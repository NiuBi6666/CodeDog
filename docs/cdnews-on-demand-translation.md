# CDNews 按需全文翻译

采集仍保存完整英文原文。标题任务仅翻译标题，完成即进入公开列表。列表和 GET 详情不触发全文任务。
读者显式点击列表标题、相关报道或直达文章路由后，前端 POST /api/news/{id}/translation 持久化全文请求，并轮询 GET 详情。

- 首页不自动选择第一篇，避免隐式请求全文。
- 标题使用现有 translateSelection 的引擎、API 模式和缓存；全文使用现有段落翻译、1:1 校验、缓存和重试。
- 标题任务与正文任务使用独立调度器；正文仅领取 body_requested_at 非空的记录。
- 多人或重复打开同一篇只设置一次请求时间，数据库原子领取，已完成全文直接复用。
- 新增接口为公开阅读动作，明确加入 POST 安全白名单并要求 CSRF；未有中文标题且尚未完成翻译的文章不能触发。
- 新增动作记录 body_translation_request 审计，保留文章 ID 和请求上下文，不记录正文和凭据。
- 原有管理权限与管理 API 保持不变。全文失败不隐藏标题；等待期间可先读英文。
- V137 仅增量添加请求时间、标题租约和标题重试字段；已有完整译文继续复用，不删除任何文章或译文。
