# 新闻正文清理

采集时先排除导航、页脚与表单。中新网使用已验证的 left_zw 正文区域，避免将相邻的“新闻精选”推荐列表提取为正文；保留页面标题和元数据。

HTML 提取、RSS 全文与 Reader 返回内容统一经过尾部检查。仅在独立推荐区标题（含各频道“××新闻精选”）后，至少有两条且全部属于纯时间戳或 Markdown 推荐链接时，删除该尾部模块。正文日期、直播时间线、普通段落中的“相关阅读”等文字不作全局删除。清理后重新检查正文长度，避免无关文本使残缺文章通过门槛。

服务端入库再次校验。历史文章详情响应按相同规则清理；中英文原本对齐时使用同一截断位置。历史存储原稿与译文不重写，不影响核查、文章状态、分类、权限或审计。

验证：采集单测覆盖已知 HTML 区域、RSS 与 Reader 回退、长度门槛及误删保护；后端单测覆盖双语对齐和未翻译文章，集成测试覆盖历史文章公开响应和原稿保留。真实中新网样本 1012 验证正文结尾仍在，推荐时间戳已排除。

存量核查发现国际新闻精选 15 篇、经济新闻精选 16 篇；上线验收覆盖全部 31 个公开详情响应，检查推荐尾部被过滤且原有正文前缀保留。
