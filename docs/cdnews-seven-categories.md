# 七大新闻分类与来源语言

一级分类：国际、军事、科技、财经、教育、文娱、生活。用户清单中的 35 条 RSS 配置保存于 integrations/news/sources.json；以完整表格为准，包含中文联合国、Defense News、MIT、Nature、MarketWatch、THE、少数派等参考代码省略项。已有 BBC、卫报垂直源保留为补充源。

V139 增量添加来源与文章 sub_tag/lang，科学、环境归科技，健康归生活，体育、文化归文娱。保留旧文章 ID、URL 指纹、原文和现有译文；不重置翻译、不删除文章。英文在上中文在下的排版不变。元数据修改默认影响后续采集，不批量改写已发布文章。

来源管理可配置分类、二级标签、en/zh 语言、频率和权重，沿用 news.sources.create/update 与字段审计。语言和分类由可信来源配置决定，不接受采集包自行指定语言以绕过翻译。标签长度限制 40 字符，拒绝控制字符，只允许七类和两种语言。

公开 GET /api/news 增加 sub_tag 可选筛选、sub_tags 可用主题；文章带 lang/sub_tag/title_original，详情增加 content_original。历史 title_en/content_en 列作为兼容原稿存储保留，中文原稿在 API/页面由 lang=zh 和原文字段明确标识。中文按字符长度校验，直接写入原稿与中文展示字段，标记 ready，不调用翻译引擎；页面不生成虚假的英文对照。英文保持标题预译、打开详情才译正文，不生成摘要。

立即同步只 GET 当前分类/子标签的已入库报道，不触发采集。海外 GitHub 后台按源到期间隔抓取；管理员仍可手动启动独立采集。内部快采任务覆盖最多 100 个源，避免原 30 个限制遗漏新增源。保持并发与正文质量阈值、付费墙过滤和失败状态。原网页无法提取时可使用 RSS 明确的 content 全文，仍执行相同长度和付费墙检查；不使用 description/summary 冒充正文。RSS 声称全文不意味着正文必然完整，不承诺固定抓取速度或百分之百覆盖。

来源清单经管理员接口按 RSS URL 幂等导入，不覆盖 API Key、GitHub Token、Webhook 密钥。原 CNBC 综合 RSS 保留，新增 World/Finance 专题独立配置。失败来源保留错误状态，可在管理后台编辑或停用。源名中没有给出独立地址的 IGN/BBC Sport 不凭空新增，采用表中实际提供的 Polygon/ESPN 地址。

回退保留服务镜像与部署前备份；代码回退后保留新增列即可，避免删除新增稿件。七类迁移兼容旧显示，必要时通过备份还原分类元数据，不进行广泛删除。
