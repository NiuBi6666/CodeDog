# CDNews 正文翻译方式

系统管理员在 /news 的“正文翻译配置”选择：

- 默认翻译：UlionTse/translators 6.0.4，无需大模型 API Key；可选 Bing、Alibaba、Baidu。
- 大模型 API：沿用加密的 Base URL / model / API Key 配置。

未选择过方式且未配置模型时默认 translators/Bing；已有完整模型配置继续用 API，避免意外切换。保存方式后立即用于后续任务；既有文章如需更换译文可手动重新编译。切换到默认翻译保留已加密的模型密钥，不会调用模型，也不自动降级或跨引擎重试。

两种方式仅翻译正文，原新闻标题直接展示，不生成标题或摘要。translators 长段按边界拆分请求，返回时合并回原段，严格校验段落数量。原摘要字段仅为历史数据兼容保留，前端不展示。

Python 翻译服务只在专用 Docker 网络内供 backend 访问，不发布宿主机端口；不在浏览器执行。其健康检查只代表进程存活，不能代替后台的真实引擎连接测试。请求串行处理、有限时/限量；失败沿用新闻队列退避重试及后台失败状态，不发布空译文。

translators 是第三方在线翻译服务的开源调用封装，并非离线模型。可用性、限流和使用条款由各翻译提供方决定。文章正文会发送至所选翻译服务。默认翻译不具备大模型的领域提示能力。
