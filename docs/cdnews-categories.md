# CDNews 新闻分类
分类为科技、国际、财经、教育、科学、健康、环境、体育、文化、生活。全部为聚合视图。
公开导航单行横向滚动，手机保留固定字宽，不挤压文字。来源管理选项和后端白名单一致。
新增官方英文源：BBC Science（科学）、BBC Health（健康）；The Guardian Environment、Sport、Culture、Lifestyle 对应环境、体育、文化、生活。
分类由订阅源栏目确定；不借助摘要生成或大模型改写分类。既有文章、来源分类不批量修改。
新增源每 10 分钟到期，尊重海外任务调度与正文质量校验；创建后需等待成功采集和标题翻译后才有可见文章，空分类不会用演示数据填充。
管理端仍使用原有 news.sources.create/update 权限、CSRF 与字段审计，无新增匿名管理接口。集成测试覆盖新增分类、无效分类、授权和撤权后的拒绝。
