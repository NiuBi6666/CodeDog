# CDNews 读库刷新与后台采集

- 公开页“立即同步”仅 GET /api/news，保留分类、来源和搜索条件，重置到第一页，不再 POST /api/user/refresh，不再轮询采集任务。请求失败显示错误，不宣称同步成功。
- 后台海外 GitHub Actions 每小时 03、13、23、33、43、53 分钟尝试运行，避开整点高峰。Actions 可能延迟，不能承诺十分钟内必达；并发组不取消已运行采集。
- 启用的官方英文订阅源刷新间隔设为 10 分钟；后续管理员仍可独立调整。每次启动按来源到期时间领取，不忽略配置。
- 来源仍为 BBC News、The Guardian、TechCrunch、CNBC、EdSurge，无国内二手源。付费墙、反爬、提取失败会造成缺报，不承诺 100% 完整。
- 默认 translators / Bing。英文原文保留，段落英文在上、中文在下；标题先译，正文仍只在用户打开后翻译。失败不以英文充当中文，不生成摘要。
- 管理端的手动采集、权限、CSRF 与审计保持原有接口。公开读库刷新不创建采集任务、不触发外部费用。
- 回退：保留部署前 news-web 镜像；Git 回退本次前端和工作流；订阅源间隔可通过原管理接口恢复，已入库文章不受影响。
