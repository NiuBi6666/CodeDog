# 新闻列表上滑加载

按原新闻 published_at 倒序，同一时间以 id 倒序保证稳定排序。
GET /api/news 支持 cursor；返回 has_more 和 next_cursor。游标由末条文章的精确发布时间与 ID 组成。沿用现有一级分类、来源、关键词过滤，兼容旧 page 请求。
只读公开接口权限不变，不新增管理或写入接口，采集和翻译策略不变。
前端移除底部加载更多按钮，手机使用页面视口、桌面使用左侧独立滚动容器观察列表末尾。距离末尾 120px 自动读取更早报道。
同一列表仅允许一次追加请求，成功后才推进游标；按 ID 合并避免重复。筛选变化使旧请求失效，失败保留已加载列表，显示重试；没有更多数据显示已浏览全部报道。
测试覆盖同时间排序、并发新头条不影响游标分页、无重复与无漏页、错误游标、桌面和移动滚动、失败重试、筛选竞争。

用户端已移除“立即同步”按钮及其请求、提示和样式。列表在打开页面或切换筛选时读取数据库，滚动继续加载较早新闻；后台定时采集独立运行。
