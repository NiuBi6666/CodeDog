# 新闻列表上滑加载

按原新闻 published_at 倒序，同一时间以 id 倒序保证稳定排序。
GET /api/news 支持 cursor；返回 has_more 和 next_cursor。游标由末条文章的精确发布时间与 ID 组成。沿用现有分类、来源、关键词、二级标签过滤，兼容旧 page 请求。
只读公开接口权限不变，不新增管理或写入接口，采集和翻译策略不变。
前端移除底部加载更多按钮，手机使用页面视口、桌面使用左侧独立滚动容器观察列表末尾。距离末尾 120px 自动读取更早报道。
同一列表仅允许一次追加请求，成功后才推进游标；按 ID 合并避免重复。筛选变化使旧请求失效，失败保留已加载列表，显示重试；没有更多数据显示已浏览全部报道。
顶部立即同步只查询第一页；若首条 (published_at,id) 不大于当前首条，保持文章数组、统计数字、已加载页与滚动位置不变，提示暂无更新的报道。更早文章补录不会重置列表。真正有更新时更新第一页并回到列表顶部。
测试覆盖同时间排序、并发新头条不影响游标分页、无重复与无漏页、错误游标、桌面和移动滚动、失败重试、筛选竞争、无更新不重刷和真实新报道刷新。
